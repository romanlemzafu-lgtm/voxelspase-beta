# VoxelSpase — бета

Мессенджер для друзей и небольших групп: личные сообщения, голосовые комнаты, группы. Работает в браузере.

**Статус: бета, для просмотра.** Не production. Список изменений — в CHANGELOG.md.

## Как устроено
- Статический сайт: `index.html` (лендинг), `app/` (приложение), остальные папки — языковые версии и страницы.
- `_worker.js` — загрузка аватаров и баннеров (`/api/media`). Работает только на Cloudflare Pages.
- `_headers` — заголовки безопасности. Тоже только на Cloudflare Pages.
- Backend — Supabase (авторизация, база, хранилище). Ключи в репозиторий не кладутся.

**GitHub Pages не подходит:** на нём не работают `_worker.js` и `_headers`, аватары не загрузятся.

## Как поднять бету (Cloudflare Pages + GitHub)
1. Cloudflare → Workers & Pages → Create → Pages → Connect to Git → выбрать этот репозиторий.
2. Build command: пусто. Build output directory: `/` (корень).
3. Production branch: `main` (его не трогать без решения владельца). Для беты используем preview-ветку или отдельный проект Pages.
4. Settings → Variables and Secrets:
   - `VOXEL_STORAGE_SECRET` — серверный секрет для загрузки файлов. Тип Secret. Значение не публиковать.
   - `SUPABASE_URL` — только если отличается от проекта по умолчанию.
5. Supabase → Authentication → URL Configuration: добавить адрес беты в Redirect URLs (`https://<адрес беты>/app/` и `/app/?recovery=1`). У каждой preview-ветки свой адрес — лучше один фиксированный адрес беты.

## Что проверить в бете
- Регистрация и письмо подтверждения.
- Вход и восстановление пароля.
- Загрузка и сохранение аватара; картинка остаётся после обновления страницы.
- Личные сообщения, группы, голосовые комнаты, капсула.
- Темы: «Персик» (вариант), «Закат», «Своя».
- Ошибки загрузки показывают понятный текст.

## Не в этой сборке
- Пчёлка и звук (источник файла не подтверждён).
- Pro-темы и Premium (серверных прав нет).
